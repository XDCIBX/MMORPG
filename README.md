# Три Короны — браузерная 3D RPG в стиле MMORPG

Открытый мир 1,6 × 1,6 км с тремя городами, пятью классами, ветками развития, боссами, тайными лавками и сюжетными цепочками заданий. Вся графика процедурная: модели персонажей, доспехи, оружие, монстры, здания, текстуры и эффекты создаются кодом на [Three.js](https://threejs.org/). Сторонние ассеты не нужны.

## Как запустить

Готовая сборка лежит в `dist/game.js`, поэтому достаточно **открыть `index.html` в браузере** (Chrome, Edge или Firefox; нужна поддержка WebGL2).

Если браузер блокирует локальные файлы, запустите простой сервер:

```bash
npm install
npm run serve        # http://localhost:8080
```

Пересборка после изменения кода:

```bash
npm run build        # минифицированная сборка в dist/game.js
npm run watch        # сборка с отслеживанием изменений
```

## Телефоны и планшеты (iPhone, Android)

Игра работает в мобильном браузере (Safari на iOS 15+, Chrome на Android) в **горизонтальной ориентации**. Сенсорное управление включается автоматически:

- **левая часть экрана** — джойстик (появляется под пальцем): движение;
- **свайп в правой части** — поворот камеры, **два пальца** — приближение;
- **касание врага** — выбор цели, повторное касание — атака; **касание NPC** — разговор;
- **кнопка ⚔** — атака ближайшего врага; вокруг неё по дуге — умения 1–9;
- **⤒ ⟳ 💬 🧪 💧** — прыжок, следующая цель, разговор с NPC рядом, зелья;
- в сумке: касание — описание предмета, повторное — надеть, долгое нажатие — продать.

На телефонах автоматически включается облегчённая графика (меньше дальность травы и тумана, тени 1024). Её можно поменять в меню ⚙. На Android кнопка «На весь экран» прячет панели браузера. На iPhone лучше добавить игру на экран «Домой» (Safari → «Поделиться» → «На экран „Домой“»): тогда она запускается на весь экран.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение, `Q`/`E` — шаг в сторону |
| ЛКМ/ПКМ (зажать) | вращение камеры; обе кнопки — бег вперёд |
| Колесо мыши | приближение камеры |
| `Пробел` | прыжок |
| ЛКМ по цели | выбрать цель; **ПКМ** — атаковать / поговорить |
| `Tab` | ближайший враг |
| `1`–`9` | умения (1–6 основные, 7–9 — умения ветки развития) |
| `Z` / `X` | зелье здоровья / маны |
| `F` | говорить с NPC, камень телепортации |
| `C` `B` `L` `K` `M` | персонаж, сумка, задания, умения, карта мира |
| `Esc` | закрыть окна / меню (сохранение, качество графики, звук) |

## Мир

| Город | Уровни | Окрестности |
|---|---|---|
| **Светлолесье** (юго-запад, фахверковый городок) | 1–30 | волки, кабаны, гоблины, пауки, разбойники, медведи, скелеты, орки-разведчики |
| **Каменград** (восток, гномья крепость) | 30–70 | тролли, ящеры, каменные големы, орки-берсерки, призраки, минотавры, падшие рыцари |
| **Аврелион** (север, белокаменная цитадель) | 70–100 | йети, огненные элементали, демоны, ледяные великаны, культисты, огненные дрейки |

Биомы: Изумрудные холмы, Шепчущий лес, Сизые нагорья, Гнилые топи, Проклятая чаща, Ледяной предел, Пепельные земли с лавовыми озёрами. Цикл дня и ночи, погодный туман по биомам, вода, трава и деревья, качающиеся на ветру.

**Боссы** (с них падает уникальное легендарное и эпическое оружие, доспехи и украшения):

1. Сумрачный Клык, ур. 25: вожак Теневой стаи, логово на северо-западе от Светлолесья
2. Королева Арахна, ур. 42: Гнездо в Гнилых топях
3. Каменный Колосс, ур. 60: Древняя Кузня в нагорьях
4. Малгорот, Ледяной Лич, ур. 82: склеп в Ледяном пределе
5. Игнириус Древний, ур. 100: Пик Игнириуса в Пепельных землях

У боссов есть механики с предупреждающими кругами на земле (удары по области, прыжки, призыв помощников, ядовитые лужи, камнепад, ледяная нова, огненное дыхание) и фаза ярости.

**Тайные лавки** спрятаны по всему миру (хижина отшельника, пещера контрабандистов, шалаш болотной ведьмы, гномий тайник, лагерь Странника Пустоши). Там продаются редкое, эпическое и легендарное снаряжение. Найденные лавки отмечаются на карте.

## Классы и ветки развития (с 40 уровня)

| Класс | Роль | Ветка A | Ветка B |
|---|---|---|---|
| Гном | танк (молот/топор + щит) | Хранитель Горы | Рунный берсерк |
| Воин | ближний бой (меч/двуручник) | Паладин | Мастер клинка |
| Лучник | дальний бой (лук + колчан) | Следопыт (дух-волк) | Снайпер |
| Маг | магия стихий (посох + сфера) | Светлый маг | Тёмный маг |
| Некромант | призыватель (костяной посох/коса) | Повелитель Легиона | Жнец Душ |

У каждого класса 6 базовых умений и по 3 уникальных умения в каждой ветке. Ветка даёт пассивные бонусы, ауру, а у мага меняет цвет мантии: светлую или тёмную.

## Снаряжение

11 слотов: голова, плечи, грудь, руки, ноги, ступни, оружие, вторая рука, амулет и два кольца. Всё надетое (кроме украшений) **видно на персонаже**: латы, кожа и ткань выглядят по-разному, вид зависит от тира (железо → … → небесное), а у эпических вещей появляются плащи, шипы, рога и светящиеся камни. Пять степеней редкости: обычный, необычный, редкий, эпический, легендарный.

## Задания

42 задания в трёх сюжетных цепочках: убить монстров, собрать трофеи, исследовать место, найти тайную лавку, поговорить с NPC в другом городе, победить босса. Над NPC горят маркеры «!» и «?», цели заданий подсвечиваются на мини-карте и карте мира.

Прогресс сохраняется автоматически в `localStorage` браузера.

## Структура кода

```
src/
  core/      — шум, ГПСЧ, процедурные текстуры
  world/     — ландшафт, растительность, города, локации, коллизии, небо и день/ночь
  chars/     — гуманоид со скелетом и анимациями, доспехи и оружие, существа
  data/      — классы, умения, предметы, монстры, задания, карта мира
  game/      — игрок, бой, умения, ИИ монстров и боссов, NPC, журнал заданий
  fx/        — частицы и эффекты умений
  ui/        — интерфейс, иконки предметов
```
