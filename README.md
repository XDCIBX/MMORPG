# Три Короны — браузерная 3D RPG в стиле MMORPG

Открытый мир 1,6 × 1,6 км с тремя городами, пятью классами, ветками развития, боссами, тайными лавками и сюжетными цепочками заданий. Вся графика процедурная: модели персонажей, доспехи, оружие, монстры, здания, текстуры и эффекты создаются кодом на [Three.js](https://threejs.org/). Сторонние ассеты не нужны.

## Как запустить

Готовая сборка лежит в `dist/game.js`, поэтому достаточно **открыть `index.html` в браузере** (Chrome, Edge или Firefox; нужна поддержка WebGL2).

Если браузер блокирует локальные файлы, запустите простой сервер:

```bash
npm install
npm run serve        # http://localhost:8080
```

Пересборка после изменения кода:

```bash
npm run build        # минифицированная сборка в dist/game.js
npm run watch        # сборка с отслеживанием изменений
```

## Телефоны и планшеты (iPhone, Android)

Игра работает в мобильном браузере (Safari на iOS 15+, Chrome на Android) в **горизонтальной ориентации**. Сенсорное управление включается автоматически:

- **левая часть экрана** — джойстик (появляется под пальцем): движение;
- **свайп в правой части** — поворот камеры, **два пальца** — приближение;
- **касание врага** — выбор цели, повторное касание — атака; **касание NPC** — разговор;
- **кнопка ⚔** — атака ближайшего врага; вокруг неё по дуге — умения 1–9;
- **⤒ ⟳ 💬 🧪 💧** — прыжок, следующая цель, разговор с NPC рядом, зелья;
- в сумке: касание — описание предмета, повторное — надеть, долгое нажатие — продать.

На телефонах автоматически включается облегчённая графика (меньше дальность травы и тумана, тени 1024). Её можно поменять в меню ⚙. На Android кнопка «На весь экран» прячет панели браузера. На iPhone лучше добавить игру на экран «Домой» (Safari → «Поделиться» → «На экран „Домой“»): тогда она запускается на весь экран.

## Управление

| Клавиша | Действие |
|---|---|
| `W A S D` | движение, `Q`/`E` — шаг в сторону |
| ЛКМ/ПКМ (зажать) | вращение камеры; обе кнопки — бег вперёд |
| Колесо мыши | приближение камеры |
| `Пробел` | прыжок |
| ЛКМ по цели | выбрать цель; **ПКМ** — один удар по цели / поговорить (герой бьёт только по нажатию) |
| `Tab` | ближайший враг |
| `1`–`9` | умения (1–6 основные, 7–9 — умения ветки развития) |
| `Z` / `X` | зелье здоровья / маны |
| `F` | говорить с NPC, камень телепортации |
| `G` | призвать скакуна / спешиться |
| `C` `B` `L` `K` `M` | персонаж, сумка, задания, умения, карта мира |
| `Esc` | закрыть окна / меню (сохранение, качество графики, звук) |

## Мир

| Город | Уровни | Окрестности |
|---|---|---|
| **Светлолесье** (юго-запад, фахверковый городок) | 1–30 | волки, кабаны, гоблины, пауки, разбойники, медведи, скелеты, орки-разведчики |
| **Каменград** (восток, гномья крепость) | 30–70 | тролли, ящеры, каменные големы, орки-берсерки, призраки, минотавры, падшие рыцари |
| **Аврелион** (север, белокаменная цитадель) | 70–100 | йети, огненные элементали, демоны, ледяные великаны, культисты, огненные дрейки |

Биомы: Изумрудные холмы, Шепчущий лес, Сизые нагорья, Гнилые топи, Проклятая чаща, Ледяной предел, Пепельные земли с лавовыми озёрами. Цикл дня и ночи, погодный туман по биомам, вода, трава и деревья, качающиеся на ветру.

**Боссы** (с них падает уникальное легендарное и эпическое оружие, доспехи и украшения):

1. Сумрачный Клык, ур. 25: вожак Теневой стаи, логово на северо-западе от Светлолесья
2. Королева Арахна, ур. 42: Гнездо в Гнилых топях
3. Каменный Колосс, ур. 60: Древняя Кузня в нагорьях
4. Малгорот, Ледяной Лич, ур. 82: склеп в Ледяном пределе
5. Игнириус Древний, ур. 100: Пик Игнириуса в Пепельных землях

У боссов есть механики с предупреждающими кругами на земле (удары по области, прыжки, призыв помощников, ядовитые лужи, камнепад, ледяная нова, огненное дыхание) и фаза ярости.

**Тайные лавки** спрятаны по всему миру (хижина отшельника, пещера контрабандистов, шалаш болотной ведьмы, гномий тайник, лагерь Странника Пустоши). Там продаются редкое, эпическое и легендарное снаряжение. Найденные лавки отмечаются на карте.

## Классы и ветки развития (с 40 уровня)

| Класс | Роль | Ветка A | Ветка B |
|---|---|---|---|
| Гном | танк (молот/топор + щит) | Хранитель Горы | Рунный берсерк |
| Воин | ближний бой (меч/двуручник) | Паладин | Мастер клинка |
| Лучник | дальний бой (лук + колчан) | Следопыт (дух-волк) | Снайпер |
| Маг | магия стихий (посох + сфера) | Светлый маг | Тёмный маг |
| Некромант | призыватель (костяной посох/коса) | Повелитель Легиона | Жнец Душ |

У каждого класса 6 базовых умений и по 3 уникальных умения в каждой ветке. У каждого умения своя постановка: движение героя (бросок из-за головы, прыжок с ударом, молитва на колене, призыв из земли, взмах косой и другие), подготовка (сбор энергии, магический круг своей школы — огня, льда, света, тени, смерти, природы, земли), сам удар (росчерк клинка, ветвящаяся молния, луч, град стрел, втыкающихся в землю) и последствия (трещины, столбы пламени, дым, осколки, черепа душ). Постановки лежат в `src/game/skillfx.js`, приёмы для них — в `src/fx/vfx.js`. Ветка даёт пассивные бонусы, ауру, а у мага меняет цвет мантии: светлую или тёмную.

## Монстры

Волки, медведи и кабаны вылеплены по анатомии как цельные тела со скелетом, ходят шагом, рысью и галопом, у них объёмная шерсть из слоёв-оболочек (длиннее на загривке и хвосте) и окрас по зонам. Пауки — с хитином, узором на брюшке, восемью глазами, хелицерами и суставчатыми волосатыми ногами. Дракон и дрейки — с чешуёй (крупной на спине, поперечными щитками на брюхе), рогами, гребнем шипов и складными перепончатыми крыльями. Каменные големы — из колотых глыб с раскалёнными прожилками, огненный элементаль — пламя на обсидиановом каркасе, призрак — в рваном светящемся саване. Гуманоидные монстры (орки, гоблины, тролли, ящеры, минотавры, демоны, йети, падшие рыцари, лич) — на детальных телах с вылепленными головами. Просмотр: `tools/creatures/index.html?list=wolf,spider`.

В бою: стоп-кадр и толчок камеры на сильных попаданиях, ударная волна искажения от взрывов, отбрасывание и вздрагивание врагов, опалины на земле, свой звук у каждой стихии умений.

## Ездовые животные

Клавиша `G` (на телефоне кнопка 🐎) призывает скакуна, у каждого класса свой: боевой тяжеловоз гнома (рыжий, со светлой гривой и «щётками» над копытами), вороной боевой конь воина в латной броне и попоне, гнедой лесной скакун лучника с седельными сумками, серый в яблоках единорог мага, конь-призрак некроманта с рогами и светящейся гривой. Лошади вылеплены по анатомии как единая модель со скелетом и ходят шагом, рысью и галопом. Верхом герой бежит почти вдвое быстрее. Призвать скакуна нельзя в бою и в воде, а атака, умение или полученный удар сбрасывают с седла.

## Снаряжение

11 слотов: голова, плечи, грудь, руки, ноги, ступни, оружие, вторая рука, амулет и два кольца. Всё надетое (кроме украшений) **видно на персонаже**: латы, кожа и ткань выглядят по-разному, вид зависит от тира (железо → … → небесное), а у эпических вещей появляются плащи, шипы, рога и светящиеся камни. Пять степеней редкости: обычный, необычный, редкий, эпический, легендарный.

## Города, горы и физика

В центре каждого города свой фонтан: двухъярусный с дугами струй в Светлолесье, восьмигранный гномий с рунным столпом и наковальней в Каменграде, парадный трёхъярусный с золотым солнцем и водяными завесами в Аврелионе. Вода шейдерная: рябь расходится от мест падения струй, видны отражение неба, блики и пена. На улицах — гирлянды флажков, клумбы, колодцы, телеги, сено, поленницы, вывески и цветочные ящики на домах, дым из труб; знамёна колышутся на ветру.

Горы стоят массивами: хребты с отрогами и седловинами, вогнутые склоны (круто у вершин, полого к подножию), предгорья с округлыми холмами. Рельеф размыт эрозией: осыпание круче угла естественного откоса и 450 тысяч «дождевых капель», которые прорезали ложбины и кулуары и вынесли грунт к подножию. Выше границы леса выходит скала, выше снеговой линии снег лежит на пологих местах и в ложбинах (в Ледяном пределе — ниже, в остальных горах — только у вершин). Дороги идут долинами и перевалами, вокруг городов, мест, озёр и стоянок монстров — пологие подступы.

Эрозия считается заранее (`npm run bake:terrain` → `models/terrain_heights.js`, ~600 КБ), игра только читает карту высот; если файла нет, рельеф строится при загрузке с облегчённой эрозией. Генератор (`src/world/heightmap.js`, `src/world/erosion.js`) не зависит от браузера: `tools/terrain/preview.mjs` считает его в node, `tools/terrain/index.html` показывает только ландшафт.

Бочки, ящики, тыквы и вёдра — предметы с физикой: их можно толкать на бегу и верхом, раскидывать ударами и умениями по области; они катятся по склонам и сталкиваются друг с другом и со стенами.

Горожане, стражники и квестовые персонажи на компьютере используют детальные запечённые модели (`models/hero_npc_*.js`): человек, женщина и гном с наборами причёсок и одежды.

## Модели героев

Герои всех классов (мужчина и женщина) — отдельные детальные модели, вылепленные заранее генератором в `tools/bake/` и сохранённые в `models/hero_*.js` (около 50 тыс. треугольников на тело плюс броня). Тело цельное, с мышцами, кистями, сжатыми в хват, стопами и прорисованным лицом (веки, губы, брови, уши); волосы и бороды объёмные. Для каждого слота брони есть облегающие детали: латы (кираса с ребром жёсткости, набедренные пластины, наплечники, латные перчатки, поножи, сабатоны, три вида шлемов), кожаный доспех лучника (куртка с полами, перевязь, наручи, сапоги, капюшон или шапка с пером) и одежда магов (мантия, пелерина, шляпа, капюшон, обруч). Оружие и щиты (`models/hero_weapons.js`) тоже запечённые: клинки с долом, обмотка рукоятей, топоры, молоты, луки, посохи, коса, щиты с умбоном.

Модель класса подгружается при выборе героя; пока она грузится, показывается упрощённая. Пересобрать модели: `npm run bake` (несколько минут), посмотреть: `tools/viewer/index.html?key=warrior_m` после `npm run viewer`.

## Задания

42 задания в трёх сюжетных цепочках: убить монстров, собрать трофеи, исследовать место, найти тайную лавку, поговорить с NPC в другом городе, победить босса. Над NPC горят маркеры «!» и «?», цели заданий подсвечиваются на мини-карте и карте мира.

Прогресс сохраняется автоматически в `localStorage` браузера.

## Структура кода

```
src/
  core/      — шум, ГПСЧ, процедурные текстуры
  world/     — ландшафт, растительность, города, локации, коллизии, небо и день/ночь
  chars/     — гуманоид со скелетом и анимациями, доспехи и оружие, существа, лошади
  chars/hero — детальные модели героев: анатомия, волосы, броня, оружие (лепка для генератора), загрузка и материалы
tools/bake  — генератор моделей героев (node): полигонизация, упрощение, веса, сжатие
models/     — запечённые модели героев и оружия
  data/      — классы, умения, предметы, монстры, задания, карта мира
  game/      — игрок, бой, умения, ИИ монстров и боссов, NPC, журнал заданий
  fx/        — частицы и эффекты умений
  ui/        — интерфейс, иконки предметов
```
